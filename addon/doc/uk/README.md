# Легке копіювання таблиці

**Легке копіювання таблиці** — це додаток для NVDA, розроблений для вирішення поширеної проблеми: копіювання таблиць або списків з веб-сторінок або з Windows у документи (наприклад, Word, Excel або Outlook) без втрати форматування, меж або структури.

## 1. Основні функції

* **Подвійний механізм копіювання:** Виберіть режим «Стандартний» для найкращої візуальної точності або режим «Відновлений» для гарантованої цілісності структури.
* **Підтримка веб-списків:** Копіюйте списки з веб-сторінок, використовуючи два варіанти — збереження оригінального форматування (шрифти, кольори, посилання) або копіювання у вигляді чистого простого списку (включно з текстом кнопок та інтерактивних елементів). Позначте окремі елементи, щоб скопіювати їх частину.
* **Розумний вибір:** Легко вибирайте несуміжні рядки або елементи списку, або конкретні стовпці, щоб скопіювати їх пакетом.
* **Підтримка робочого столу та Провідника:** Миттєво перетворюйте списки Провідника файлів або вікна програм на таблиці, які можна скопіювати. Копіюйте конкретні стовпці або комбінації стовпців.
* **Ієрархічне копіювання TreeView:** Копіюйте вкладені деревоподібні структури (наприклад, діалог «Жести вводу») з правильним відступом та станами розгортання.
* **Копіювання на рівні комірок:** Швидко копіюйте вміст окремих комірок без навколишньої структури таблиці.
* **Статистика таблиці:** Отримуйте миттєву інформацію про розміри таблиці (кількість рядків і стовпців) будь-де.
* **Звуковий супровід:** Характерні звуки та голосові повідомлення інформують вас про процес копіювання.

## 2. Веб-режим (браузери)

Ця функція працює в режимі огляду у браузерах (Chrome, Edge, Firefox тощо).

### A. Меню копіювання таблиці

Перейдіть у будь-яку таблицю на веб-сайті та натисніть `NVDA + Alt + T`, щоб відкрити меню дій.

* **Копіювати таблицю (стандартно):**
Використовує вбудовану функцію копіювання браузера.
*Переваги:* Зберігає точні шрифти, кольори фону та посилання.
*Недоліки:* Залежить від браузера; порожні комірки можуть зливатися в деяких цільових програмах.
* **Копіювати таблицю (відновлено):**
«Безпечний режим». Додаток ігнорує браузер і вручну відтворює таблицю з нуля.
*Переваги:* **Гарантує**, що порожні комірки будуть заповнені (зі збереженням меж), та застосовує лінії сітки.
*Недоліки:* Може втратити складне CSS-оформлення (наприклад, закруглені кути).
* **Копіювати поточний рядок:** Копіює лише той рядок, у якому знаходиться курсор (стандартний режим).
* **Копіювати поточний стовпець:** Вручну виокремлює та копіює вертикальний стовпець, у якому знаходиться курсор.

### Б. Меню копіювання списку

Перейдіть до будь-якого списку на веб-сайті (маркованого або нумерованого) і натисніть `NVDA + Alt + T`, щоб відкрити меню копіювання списку.

* **Копіювати список (з форматуванням):**
Використовує вбудовану функцію копіювання браузера.
*Переваги:* Зберігає точні шрифти, кольори, посилання та всі інші елементи оригінального стилю.
*Недоліки:* Залежить від браузера.
* **Копіювати список (простий):**
Додаток зчитує елементи списку та створює чисту структуру `<ul><li>`. Текст кнопок та мітки інтерактивних елементів (наприклад, «Керувати файлами cookie») тепер включені до простого виводу.
*Переваги:* Створює чистий, переносимий список. Кожен елемент знаходиться у власному рядку у вигляді простого тексту.
*Недоліки:* Оригінальне візуальне оформлення (шрифти, кольори) не зберігається.
* **Копіювати позначені (N елементів):** *(з'являється лише тоді, коли елементи позначені)*
Копіює лише ті елементи, які ви позначили окремо. Див. **Розумний вибір** нижче.
* **Очистити вибране:** *(з'являється лише тоді, коли елементи позначені)*
Видаляє всі поточні позначки без копіювання.

### C. Розумний вибір (маркування)

Ви можете вибрати конкретні елементи для пакетного копіювання. Ця функція працює як для **рядків таблиці**, так і для **елементів веб-списку**. **Примітка:** Ви можете позначити рядки/елементи АБО стовпці, але не обидва одночасно.

#### Як скопіювати певні рядки або елементи списку:

1. Перейдіть до рядка або елемента списку, який потрібно скопіювати.
2. Натисніть `Control + Alt + Пробіл`. NVDA підтвердить: «Позначений рядок» (у таблицях) або «Позначений елемент» (у списках).
3. Перейдіть до іншого рядка або елемента та повторіть.
4. Відкрийте меню (`NVDA + Alt + T`) і виберіть **"Копіювати позначені"**.

#### Як скопіювати певні стовпці:

1. Перейдіть до комірки у потрібному стовпці.
2. Натисніть `Control + Alt + Shift + пробіл`. NVDA підтвердить: «Стовпець позначено».
3. Повторіть ці дії для інших стовпців.
4. Відкрийте меню та виберіть **«Копіювати позначене»**.

> **Примітка:** щоб очистити вибір, натисніть `Control + Alt + Windows + пробіл` або скористайтеся опцією «Очистити вибір» у меню (також доступною в меню списку, коли елементи позначено).

### D. Додаткові веб-функції

* **Копіювати вибрані рядки як текст:** Після вибору рядків їх можна скопіювати у вигляді простого тексту без структури таблиці за допомогою команди «Копіювати вибране як текст» (початкова клавіша відсутня, призначте її в розділі «Жести вводу»).
* **Копіювати поточну комірку:** Швидко скопіюйте вміст поточної комірки за допомогою команди «Копіювати поточну комірку».

## 3. Робочий стіл, Провідник та режим дерева (Windows)

Додаток також працює у Провіднику файлів, стандартних списках та ієрархічних деревах.

### A. Швидкий список та копіювання дерева

1. Виберіть список (наприклад, папку) або елемент дерева (наприклад, «Жести вводу»).
2. Натисніть `NVDA + Alt + T`.
3. **Результат для списків:** Весь список перетворюється на структуровану таблицю (із заголовками, такими як «Ім’я», «Дата», «Тип») і копіюється до буфера обміну.
4. **Результат для дерев:** Усе дерево сканується від кореня та копіюється як ієрархічний список з відступами.
* `[+]` позначає згорнуту гілку.
* `[-]` позначає розгорнуту гілку.

### Б. Копіювання окремих стовпців (лише для ПК та Провідника)

Ви можете копіювати окремі стовпці або їхні комбінації з будь-якого списку на робочому столі або з вікна Провідника. Ці команди працюють лише в контексті ПК (а не у браузерах).

| Команда | Опис |
| --- | --- |
| Копіювати стовпець 1 | Копіює перший стовпець (зазвичай «Назва») |
| Копіювати стовпець 2 | Копіює другий стовпець (зазвичай «Розмір» або «Тип») |
| Копіювати стовпець 3 | Копіює третій стовпець (зазвичай «Дата зміни») |
| Копіювати стовпці 1-2 | Копіює перший і другий стовпці разом |
| Копіювати стовпці 1-3 | Копіює перші три стовпці разом |
| Копіювати стовпці 1 і 3 | Копіює перший і третій стовпці (пропускаючи другий) |

**Як використовувати:**

1. Сфокусуйте будь-який список або вікно Провідника.  
2. Натисніть призначену вами клавішу для потрібної команди стовпця (початкових клавіш немає — потрібно призначити в Жестах вводу).  
3. Вибрані стовпці скопіюються у вигляді таблиці з заголовками.

### C. Статистика таблиці в режимі ПК

Натисніть команду «Статистика таблиці» (початкова клавіша не призначена), щоб почути:

* Кількість елементів у папці/списку
* Кількість стовпців

## 4. Універсальні функції (працюють всюди)

### A. Статистика таблиці

Скористайтеся командою «Статистика таблиці» в будь-якому інтерфейсі (веб-версія, ПК, Провідник), щоб миттєво отримати інформацію про поточну таблицю або список:

* Кількість рядків/елементів
* Кількість стовпців

Цей додаток інтелектуально вибірково обробляє великі таблиці, щоб надавати швидку та точну інформацію без уповільнення роботи системи.

### B. Копіювати поточну комірку

Використовуйте команду «Копіювати поточну комірку» будь-де, щоб швидко скопіювати лише вміст поточної комірки без навколишньої структури таблиці. Ідеально підходить для:

* Копіювання окремих значень із веб-таблиць
* Вибір окремих елементів зі списків
* Швидке введення даних

## 6. Важливі примітки

* **Захист у Excel/Calc:** Додаток автоматично вимикається в Excel та подібних програмах, щоб уникнути конфліктів із вбудованими функціями копіювання.
* **Обмеження щодо вибору:** Не можна одночасно вибирати рядки та стовпці. Виберіть або рядки, АБО стовпці, але не те й інше одночасно.
* **Великі таблиці:** Додаток ефективно обробляє великі таблиці. Для дуже великих веб-таблиць статистичні дані обчислюються методом вибірки для забезпечення оптимальної продуктивності.
* **Веб проти ПК:** Деякі команди є контекстними (лише для веб або лише для ПК), щоб забезпечити надійну роботу. Команди, які не застосовуються в поточному контексті, просто ігноруються.
* **Завантаження дерева:** У деяких TreeViews елементи, які ніколи не розгорталися, можуть бути недоступними для NVDA, доки до них не буде здійснено доступ.
